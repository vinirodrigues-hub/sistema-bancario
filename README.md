# Sistema bancario
Sistema bancário simples desenvolvido em python.
# Tecnologias utilizadas
- Python
# Objetivo
Projeto desenvolvido como parte dos meus estudos de Python e lógica de programação, buscando transformar os conceitos aprendidos em um programa funcional.
# Funcionalidades
- criação de senha
- sistema de login com limite de tentativas
- consulta de saldo
- depósito
- saque
- encerramento do sistema
# Sobre o projeto
O sistema simula operações basicas de uma conta bacaria através de um menu interativo no terminal. O usuário pode criar uma senha, realizar login e acessar diferentes operações da conta.
# Como executar
1. Tenha Python instalado.
2. Clone este repositório.
3. Abra a pasta do projeto no VS Code ou outro editor.
4. Execute o arquivo principal pelo terminal.
